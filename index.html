Frame Window List

Levels are ranked by how consistent a player must be to clear them, calculated from the frame window of every click. No votes, no opinions: add a level's windows and the formula places it.

    How placement works

    Each click or release has a window: the number of frames, at 240 fps, in which it can be hit. Smaller windows are harder.

    We model a player with a timing consistency of σ milliseconds, then find the σ at which that player clears the whole level about of the time. The smaller that σ is, the more consistent the player must be, so the harder the level.

    The score is 100 ÷ σ. Higher means harder. The range shown under each score is what you get if every window is off by one frame, so levels with overlapping ranges are effectively close.

    Because every extra click is another chance to fail, longer levels score higher automatically, and easy filler clicks barely change anything.
